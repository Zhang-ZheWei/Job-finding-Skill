# Contributing

Thanks for helping improve Job-finding.

## Before opening an issue

- Do not include resumes, personal contact details, cookies, tokens, complete job descriptions, or unpublished company information.
- Describe the stage (`S0`–`S6`), expected behavior, actual behavior, and a redacted reproduction path.

## Pull requests

1. Make one focused change per pull request.
2. Preserve the staged execution and safety-stop rules in `job-finding/SKILL.md`.
3. Run the checks listed in the README.
4. Update `CHANGELOG.md` when behavior visible to users changes.

Changes that access a site must respect its terms, access controls, and applicable law. Do not add code intended to bypass login, CAPTCHA, rate limits, or anti-automation measures.
